# Aqara 0.3.4 — Short update command suggestions

Typing `aq up` now offers both **Refresh devices and scenes** and **Check for an
Aqara workflow update**. Select the workflow option and press Tab to complete
`workflow:update`, or Return to check for and download an update. The same
suggestions appear for `aq upd` and `aq update`; the device-refresh option
retains its position and `aq update` continues to mean device refresh.

`aq work`, `aq workflow`, and `aq workflow:u` continue to complete the workflow
commands. `aq auto` and `aq noauto` offer the automatic-check settings.

This release includes v0.3.3's full author name and profile link, fresh update
checks after upgrades, automatic result refresh during background checks, and
manual checks against GitHub's current release list. Automatic checks run daily;
finish installation in Alfred's import dialog.

Install [Aqara-0.3.4.alfredworkflow](https://github.com/schwark/alfred-aqara/releases/download/v0.3.4/Aqara-0.3.4.alfredworkflow)
or use `aq workflow:update`.

All 179 offline tests pass on Python 3.9 and 3.14, including both update choices
and the unchanged device-refresh action for `aq update`.
