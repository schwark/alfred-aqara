# Aqara 0.3.1 — Device lists follow the selected mode

Cloud mode now shows only devices from the Cloud API. Agent devices remain in
Agent mode, so the same physical device no longer appears twice because both
inventories were appended together.

- Existing mixed caches are filtered immediately, including saved home catalogs;
  no manual refresh or reauthentication is needed.
- Fresh Cloud discovery keeps the Cloud device's name and identifier. A verified
  exact Agent endpoint match can still supply extra commands on that row.
  Names never attach controls or merge distinct Cloud devices.
- Agent mode's device catalog, saved accounts, home links, and credentials are
  preserved. Scene behavior is unchanged.

Install [Aqara-0.3.1.alfredworkflow](https://github.com/schwark/alfred-aqara/releases/download/v0.3.1/Aqara-0.3.1.alfredworkflow)
or run `aq workflow:update` and confirm the upgrade in Alfred. Continue using
`aq mode cloud` or `aq mode agent` to select a mode.

All 160 tests pass on Python 3.9 and 3.14, including regressions for imported
Agent catalogs, old mixed caches, fresh discovery, duplicate Cloud names, and
cached home switching. Release packaging uses the explicit file allowlist and
excludes credentials and account/device data.
