# Aqara 0.3.3 — Author information and update discovery

The workflow now shows **Schwark Satyavolu** as its author and links to
[the author’s GitHub profile](https://github.com/schwark), matching the Hubitat
workflow. Setup guides and install links point to this release.

- Update commands now appear while typing `aq work`, `aq workflow`, or
  `aq workflow:u`; Tab completes `workflow:update`. Matching device results
  remain available alongside these suggestions.
- Automatic checks still run daily, as in Hubitat. An upgraded workflow checks
  again on first use instead of inheriting the previous version's daily cache
  or retry delay. Alfred refreshes results while a background check runs so
  the new release appears in the current search.
- `aq workflow:update` always fetches GitHub's current release list, including
  when automatic checks are disabled. Downloads still verify checksums and
  workflow identity before opening Alfred's import dialog.

Install [Aqara-0.3.3.alfredworkflow](https://github.com/schwark/alfred-aqara/releases/download/v0.3.3/Aqara-0.3.3.alfredworkflow)
or run `aq workflow:update` and confirm the upgrade in Alfred.

All 178 offline tests pass on Python 3.9 and 3.14, including autocomplete,
upgrade cache invalidation, manual checks, and background-result refresh.
The built package's author, website, bundle identity, and version have also
been checked against the installed workflow metadata.
